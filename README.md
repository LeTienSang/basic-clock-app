# Basic Clock App
React + TypeScript + TailwindCSS

## Tính năng

- **Đồng hồ số**: Xem giờ 12h/24h, ngày tháng và giây chính xác.
- **Bấm giờ**: Tính vòng chạy (lap), đánh dấu vòng nhanh/chậm nhất.
- **Hẹn giờ**: Đếm ngược linh hoạt với vòng tiến trình trực quan.
- **Giao diện**: Chế độ Sáng/Tối (Light/Dark mode) sang trọng.

## Chạy chương trình

    ```bash
    npm install
    npm run dev
    ```
